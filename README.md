Implementación en C de una terminal interactiva, tomando a Bash como referencia principal.

- Lectura del prompt y conversión a lista de tokens y árbol sintáctico.
- Ejecución de comandos y scripts externos.
- Operadores de redirecciones, pipes, AND y OR.
- Build-ins estándar: echo, cd, export, env, unset, pwd, exit.
- Expansión de variables de entorno y wildcards.

Proyecto de 42 realizado junto a @pedrose-99.
